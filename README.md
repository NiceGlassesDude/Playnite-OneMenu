# OneMenu for Playnite

OneMenu adds a clean, always-accessible sidebar button to Playnite that opens a flyout menu for instant navigation across your custom filter presets, external apps, and tags.

## Features

* **Quick-Access Flyout Menu:** Access all your favorite library filters from a single, persistent sidebar button.
* **Hierarchical Categorization:** Organize your menu with top-level categories and nested sub-items.
* **Open Path Routing:** Create custom buttons to instantly launch external executables, open videos, or browse specific computer folders directly from your flyout menu.
* **Global Tag Search:** Enable the Tag Search toggle to add a dedicated search button to your menu. Clicking it opens a visual grid window where you can type any tag or genre and instantly see all matching games across your entire library.
* **Display Modes:** Customize how items look with Text Only, Icon Only, or Icon and Text.
* **Custom Icon Assignment & Direct Binding:** Bind directly to your existing Playnite Filter Presets.
