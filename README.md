# OneMenu for Playnite

**OneMenu** adds a clean, always-accessible sidebar button to Playnite that opens a flyout menu for instant navigation across your custom filter presets.



* **Quick-Access Flyout Menu:** Access all your favorite library filters from a single, persistent sidebar button.
* **Hierarchical Categorization:** 
  * Create top-level categories that act as direct filter shortcuts.
  * Add nested sub-items to group your library (e.g., an *Emulators* category containing *Sega*, *GBA*, *SNES*, etc.).
  **Display Modes:** You can customize how every menu item looks:
  **Text Only:** Clean, minimal text labels.
  **Icon Only:** Compact visual representation.
  **Icon and Text:** Icons positioned neatly to the left of the text labels.
  **Management:** You can reorder items with simple Move Up / Move Down buttons, assign custom icons, and bind items directly to any Playnite Filter Preset.

---

## Configuration

1. Open Playnite **Settings** (`Ctrl + P`) $\rightarrow$ **Add-ons** $\rightarrow$ **Extension settings** $\rightarrow$ **Generic** $\rightarrow$ **OneMenu**.
2. Click **Add category** to create a main menu item.
3. Configure the selected item:
   * **Title:** Give your menu item a name.
   * **Display mode:** Choose between *IconAndText*, *IconOnly*, or *TextOnly*.
   * **Icon:** Pick a custom image file for the item.
   * **Filter preset:** Select which Playnite filter preset opens when clicked.
4. *(Optional)* Click **Add sub-item** to create drop-down sub-menus inside a category.

> **Note:** An item with sub-items automatically acts as an expandable group. To turn it back into a direct filter button, simply remove its sub-items!
