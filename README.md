# OneMenu for Playnite

OneMenu adds a single button to Playnite's sidebar that opens your own flyout menu. Fill it with shortcuts to your filter presets, programs, files and folders, sort them into categories, and reach any part of your library with one click. It also comes with a fast Tag Browser and a Tags and Genre Manager for keeping large libraries tidy.

## Features

### Your own menu

* **Flyout menu:** One sidebar button opens a menu with all your shortcuts.
* **Categories and sub-items:** Build top-level categories and nest items inside them. Reorder entries, or hide them without deleting them.
* **Filter presets:** Bind any item to one of your existing Playnite filter presets and apply it with a click.
* **Open files and folders:** Create items that start a program, play a video or open any folder on your PC.
* **Display modes:** Show each item as icon only, text only, or icon and text.
* **Left side buttons:** Turn any entry into its own icon button right below the OneMenu button in the sidebar. Single items run directly, entries with sub-items open as a small menu.

### Icons

* **Icon library:** Every icon you add is kept in a library, so you can reuse it through a visual picker instead of browsing for the file again.
* **Manage Icons:** See all your icons in one place, add new ones and permanently delete the ones you no longer need. Icons that are in use are marked.
* **Custom sidebar icon:** Replace the OneMenu button icon with your own.

### Tag Browser

* **Search by tag or genre:** Type part of a tag or genre and see all matching games with their covers. Left-click to launch, right-click for more options such as favorites, install folder or showing the game in the library.
* **Built for large libraries:** The library is indexed in the background and covers load on demand, so results appear quickly even with many thousands of games.
* **Placement:** Show the Tag Browser button in the flyout menu, as a separate button in Playnite's top panel, or both.
* **Appearance:** Adjustable window size and transparency, with an optional OneMenu color scheme.

### Tags and Genre Manager

* **Rename and remove:** Clean up tags and genres and see how many games use each one.
* **Merge:** Combine several tags or genres into one with a button or by drag and drop. Renaming to a name that already exists offers to merge instead of creating a duplicate.
* **Bulk edit:** Remove several entries at once, or add and remove a tag or genre for many games in one step.
* **Top panel button:** Optionally open the manager from its own button in Playnite's top panel.

### More

* **Import and export:** Back up your menu, icons, tags and genres, or move them to another PC.
* **Themes:** Choose separately whether the Advanced Settings and the Tag Browser use OneMenu's colors or your Playnite theme.
* **Languages:** English, German, French, Spanish, Italian, Portuguese (Brazil), Russian and Chinese (Simplified).

## Getting started

1. Install OneMenu and restart Playnite. The welcome guide opens automatically.
2. Open Add-ons (F9) > Extensions settings > Generic > OneMenu.
3. Add a category, add items to it, and pick a filter preset or a file or folder for each item.
4. Save, then click the OneMenu button in the sidebar.
